sprooto v0.01 prototype

起動方法
1. VS Codeでこのフォルダを開く
2. index.htmlをLive Serverで起動する

操作
- 上の32マス：選択中trackのステップON/OFF
- track表示を左クリック：次のtrack
- track表示を右クリック：前のtrack
- 下のパラメータを押す：編集画面
- 編集画面のtrack表示を押す：パラメータ一覧へ戻る
- オフセット値を左クリック：+1
- オフセット値を右クリック：-1
- 再生ボタン：再生／停止トグル

実装済み
- 32 step / 4 track統合シーケンサー
- 8×4レイアウト
- 選択track表示
- editor通常表示／編集表示
- note / volume / sine / noise / decay / FM depth・ratio / tone / pan / probability
- sine + noise同時保持・混合
- FM、Tone、Pan、Probabilityの発音反映
- Mute / Solo
- 3カラーパレット
- PC・スマホ向けレスポンシブ表示
